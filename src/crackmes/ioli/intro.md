IOLI CrackMes
=============

The IOLI crackme is a good starting point for learning Rizin. This is a set of tutorials based on the tutorial
at [dustri](https://dustri.org/b/defeating-ioli-with-radare2.html)

The IOLI crackmes are available at a locally hosted
[mirror](https://github.com/rizinorg/book/raw/master/src/crackmes/ioli/IOLI-crackme.tar.gz)

The original binaries are 32-bit only. If you want to practice on a
64-bit system or on another architecture, [IOLI crackmes, rebuilt](https://github.com/itwaseasy/IOLI-crackmes-rebuilt)
provides the same ten crackmes compiled from C sources for Linux and
Windows on x86, x86-64 and arm64, and for macOS on x86-64 and arm64.
The rebuilds keep the logic, conditions, calls and strings of the
originals, but addresses and stack offsets differ — to follow the
walkthroughs step by step, use the original binaries above.
